MvideoInternshipJava
============

Проект для тестового задания на Java

_Версия на kotlin: [тык](https://github.com/Smkin32/mvideo_internship_kotlin)_


Допущения в условии
-------------------------
При нулевом количестве всех товаров в группе, отрицательное кол-во записывается в экземпляр товара высшего ранга 

Архитектура и зависимости
-------------------------
* Java 26
* Gradle 9.4.0

Как билдить и запускать?
------------
В корне проекта запустить:
1. ``` gradle build ```
2. ``` gradle run --args="<Путь к входному файлу> <Путь к выходному файлу>" ```
3. После выполнения программы, в директории создастся файл лога.
